# LetMeAskAI

Next time your annoying friend or coworker asks you for your help, send them this with their question. 

## Usage
You can go to the https://letmeaskai.online and prompt something, copy your prompt to get the generated link.

or

you can create it like https://letmeaskai.online/?ask=hello+world

## Develop

```bash
# setup
yarn install
# run locally
yarn start
# deploy with gh-page
yarn run deploy
# test build
yarn run predeploy
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
